# Common mistakes

| WRONG | RIGHT and source |
|---|---|
| Increase goroutines while never reaching close/reload. | Design the real lifecycle overlap; historical publication/reference-count bugs required those paths ([TSan 2009, §§6.3–7.1, pp.67–69](https://static.googleusercontent.com/media/research.google.com/en//pubs/archive/35604.pdf)). |
| Serialize every target operation with a harness mutex. | Coordinate phases without erasing competition; excessive synchronization can hide races ([TSan 2009, §6.5, p.69](https://static.googleusercontent.com/media/research.google.com/en//pubs/archive/35604.pdf)). |
| Treat a race-enabled Go host as plugin/native coverage. | Inspect actual plugin limitations and native build flags ([plugin](https://raw.githubusercontent.com/golang/go/dcc06a82727b447270b1a58cc5f86b49736e317c/src/plugin/plugin.go), [cgo path](https://raw.githubusercontent.com/golang/go/dcc06a82727b447270b1a58cc5f86b49736e317c/src/cmd/go/internal/work/exec.go)). |
| Union every published/development architecture list. | Use the selected compiler/runtime; the inspected source and article differ ([platform source](https://raw.githubusercontent.com/golang/go/dcc06a82727b447270b1a58cc5f86b49736e317c/src/internal/platform/supported.go), [guide](https://raw.githubusercontent.com/golang/website/a8b66266e226994e2ead51317bace3ee83cedab9/_content/doc/articles/race_detector.html)). |
| Silence a warning by inventing a synchronization annotation. | Establish the actual relation first; detector model knowledge changes findings ([TSan 2009, §5, pp.65–66](https://static.googleusercontent.com/media/research.google.com/en//pubs/archive/35604.pdf)). |
| Call adaptive native delay a Go or replayable scheduler. | Verify runtime support, Go exclusion and time-derived seeds ([initialization](https://raw.githubusercontent.com/llvm/llvm-project/635f30899dd0914fa89f0b3dc9a9e548e6d0ceec/compiler-rt/lib/tsan/rtl/tsan_rtl.cpp), [seed](https://raw.githubusercontent.com/llvm/llvm-project/635f30899dd0914fa89f0b3dc9a9e548e6d0ceec/compiler-rt/lib/tsan/rtl/tsan_adaptive_delay.cpp)). |
| Treat Helgrind exit0 as no report, or lock-order warning as an observed hang. | Parse retained diagnostics and distinguish result classes ([core exit options](https://valgrind.org/docs/manual/manual-core.html), [Helgrind §7.3](https://valgrind.org/docs/manual/hg-manual.html)). |
| Attribute race-only process growth to a Go heap leak. | Check detector auxiliary allocation behavior before attribution ([Go overhead](https://raw.githubusercontent.com/golang/website/a8b66266e226994e2ead51317bace3ee83cedab9/_content/doc/articles/race_detector.html)). |
