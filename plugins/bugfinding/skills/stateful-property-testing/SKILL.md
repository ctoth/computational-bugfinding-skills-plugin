# Stateful property testing

Search states and operations together. Choose this skill when independent values or syntactically valid programs rarely reach the successful API behavior under investigation. Valid sequences can establish state that direct construction misses: even with a state constructor, "there might be hidden state that we cannot easily replicate" ([RapidCheck stateful guide, Stateful testing](https://raw.githubusercontent.com/emil-e/rapidcheck/2c3c4365aca21ef4e612768fdc95b1ce8b39a651/doc/state.md)). Program generation belongs to `semantic-program-generation`; controlled interleavings belong to `schedule-exploration`; model-free crawling of a discovered UI state graph belongs to `ui-state-exploration`.

## Model the promised behavior

Read the actual public producer, enabled configuration and guarantee. Keep only contract facts in the model: logical identities, live handles, ownership, permissions and session state. Start model and system in equivalent states: "The initial state must obviously match the state of the System Under Test" ([RapidCheck stateful guide, Putting it all together](https://raw.githubusercontent.com/emil-e/rapidcheck/2c3c4365aca21ef4e612768fdc95b1ce8b39a651/doc/state.md)). Do not copy implementation caches or branches into the expected result; the model "should not be a carbon copy of the system" ([fast-check model design, Overview](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/website/docs/advanced/model-based-testing.md)).

Preserve state-establishing API calls. In Hughes's storage case, an open/close/open prefix reached hidden state that a shorter visible-equivalent setup did not, because "the first call to open *creates* the file"; an independent corruption check also exposed failures accepted by return-value checks. That prefix was the sequential setup of a parallel test with three concurrent operations ([Hughes, PDF pp. 14-16](https://publications.lib.chalmers.se/records/fulltext/232550/local_232550.pdf)). Treat that as a reason to inspect lifecycle paths, not a claim that every target needs reopening. Read [model and sequence design](references/model-and-sequences.md) for a worked object/permission experiment.

## Generate meaningful dependent operations

Select operands from current admissible state, using returned identities rather than random nonexistent handles. Hypothesis bundles carry earlier results, "allowing data to flow from one rule to another"; fast-check commands expose admissibility checks and execution separately as `check(model)` and `run(model, real)` ([Hypothesis stateful tests, v6.170.15](https://raw.githubusercontent.com/HypothesisWorks/hypothesis/9ab0be61aaaa27396fc1bbf4b34e7925cc68d1e2/hypothesis/docs/stateful.rst), [fast-check commands, Define the commands](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/website/docs/advanced/model-based-testing.md)). Values that exist only inside a callback, such as file handles, need a call nested in that callback (Nessie, [ICSE 2022](https://doi.org/10.1145/3510003.3510106), p.1495); fast-check's command list is flat, so generate a call tree as described in [JS UI and async APIs](references/ui-and-async-js.md).

Make intentional invalid transitions their own operations with documented error-and-effect expectations. Do not count a false command precondition as exercising an invalid API: fast-check skips its execution, `if (cmd.check(m)) cmd.run(m, r);` ([runner source, internalModelRun](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/packages/fast-check/src/check/model/ModelRunner.ts)). Record admitted calls, successful semantic operations and evaluated properties alongside generated sequence counts. Use `correctness-oracles` for the promised observations and `harness-sensitivity` for representative controls.

## Shrink the state and sequence together

Recompute preconditions from the reduced prefix. A command valid when generated can become invalid after earlier operations are removed; RapidCheck checks preconditions "both during generation and during shrinking" and tells authors to "always assert all preconditions" ([stateful guide, Command and Command generation](https://raw.githubusercontent.com/emil-e/rapidcheck/2c3c4365aca21ef4e612768fdc95b1ce8b39a651/doc/state.md)). Preserve the same violated guarantee while removing unrelated entities, setup and operations. Delegate general interestingness and minimality mechanics to `failure-reduction`.

Save resolved identities, executed operations, setup and observations as well as framework replay data. fast-check command replay needs `replayPath` plus assertion `seed` and `path` ("`commands` must be called with `{ replayPath: string }`"); Rapid ignores a fail file whose version "differs from rapid version" ([fast-check replay, Replay model-based tests](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/website/docs/advanced/model-based-testing.md), [Rapid engine, checkFailFile](https://raw.githubusercontent.com/flyingmutant/rapid/6706a6fd83736ba24aaf55ef2621fdf00c2c27e8/engine.go)). A framework seed does not control an external service or scheduler. Keep sequential modeling separate from concurrency claims.

## Select an existing fitting runtime route

Read only the relevant section of [runtime recipes](references/runtime-recipes.md):

- Python: Hypothesis rules, bundles, invariants and machine lifecycle ([official guide, v6.170.15](https://raw.githubusercontent.com/HypothesisWorks/hypothesis/9ab0be61aaaa27396fc1bbf4b34e7925cc68d1e2/hypothesis/docs/stateful.rst)).
- JS/TS: fast-check commands and the appropriate awaited runner ([runner source](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/packages/fast-check/src/check/model/ModelRunner.ts)). For React components (Testing Library), browser pages (Playwright) and Node callback APIs, read [JS UI and async APIs](references/ui-and-async-js.md).
- Go: Rapid `T.Repeat` / `StateMachineActions`; optional `MakeFuzz` connects a property to Go fuzzing ([state-machine source](https://raw.githubusercontent.com/flyingmutant/rapid/6706a6fd83736ba24aaf55ef2621fdf00c2c27e8/statemachine.go), [engine source, MakeFuzz](https://raw.githubusercontent.com/flyingmutant/rapid/6706a6fd83736ba24aaf55ef2621fdf00c2c27e8/engine.go)).
- C++: RapidCheck `Command<Model,Sut>` where its build integration fits ([stateful guide](https://raw.githubusercontent.com/emil-e/rapidcheck/2c3c4365aca21ef4e612768fdc95b1ce8b39a651/doc/state.md)).

Improve an existing sequence generator rather than port it for a tool name. Return the exercised contract and lifecycle, actual operation/property reach, original and reduced replay artifacts, classifications and limits. Preserve model defects and unresolved comparisons; a mismatch does not identify which side is wrong. Hughes treated early sequential inconsistencies as "a bug in the model", and describes testing as comparing "two independent descriptions" ([Hughes, PDF pp. 14, 17](https://publications.lib.chalmers.se/records/fulltext/232550/local_232550.pdf)). Read [common mistakes](references/common-mistakes.md) for misleading success signals. Campaign allocation and final attribution remain `bugfinding-campaign` and `evidence-based-triage` responsibilities.
