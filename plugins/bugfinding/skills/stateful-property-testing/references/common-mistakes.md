# Common stateful-testing mistakes

- **Wrong:** Sample unrelated object IDs and count every generated command as a deep API test. **Better:** Select useful live identities and count calls that execute; fast-check skips commands whose `check` is false: `if (cmd.check(m)) cmd.run(m, r);` ([runner source, internalModelRun](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/packages/fast-check/src/check/model/ModelRunner.ts)).
- **Wrong:** Copy the implementation's caches and decisions into its model. **Better:** Keep a simpler contract representation that can disagree for an independent reason; the model "should not be a carbon copy of the system" ([fast-check model guidance, Overview](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/website/docs/advanced/model-based-testing.md)).
- **Wrong:** A generation-time precondition proves every smaller sequence valid. **Better:** Recompute admissibility from the reduced prefix; the generator's state is "a hint to aid in generating useful commands, not a promise", so RapidCheck says to "always assert all preconditions" ([stateful guide, Command generation](https://raw.githubusercontent.com/emil-e/rapidcheck/2c3c4365aca21ef4e612768fdc95b1ce8b39a651/doc/state.md)).
- **Wrong:** Remove open/close/open because the visible state looks unchanged. **Better:** Retain the real setup until replay establishes it is irrelevant; in Hughes's parallel dets test, removing the first open and close made the smaller test pass "every single time" because the first open "*creates* the file" ([paper, PDF p. 15](https://publications.lib.chalmers.se/records/fulltext/232550/local_232550.pdf)).
- **Wrong:** All returned values match, so storage/effects are correct. **Better:** Select independent observations for the actual promise; in the same case "All results are consistent with the model—but the corruption check encountered" an error ([Hughes, PDF pp. 15-16](https://publications.lib.chalmers.se/records/fulltext/232550/local_232550.pdf)).
- **Wrong:** A skipped denial precondition tests permission enforcement. **Better:** Execute the deliberate denied call and assert its documented error and effects; a false `check` means `run` never executes ([fast-check runner, internalModelRun](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/packages/fast-check/src/check/model/ModelRunner.ts)).
- **Wrong:** pytest function-scoped fixtures reset each generated input. **Better:** Use the actual machine lifecycle; Hypothesis states "function-scoped fixtures run only once for the entire test, not per-input" ([compatibility, pytest, v6.170.15](https://raw.githubusercontent.com/HypothesisWorks/hypothesis/9ab0be61aaaa27396fc1bbf4b34e7925cc68d1e2/hypothesis/docs/compatibility.rst)).
- **Wrong:** A fast-check seed/path contains everything needed for a command replay. **Better:** Retain `replayPath` and the executed transcript too; `replayPath` "encodes the history of what was really executed" ([replay guide, Replay model-based tests](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/website/docs/advanced/model-based-testing.md)).
- **Wrong:** Go Rapid provides coverage and schedule exploration automatically. **Better:** Ordinary Rapid "lacks coverage-guided feedback and mutations"; its `MakeFuzz` adapter lets a rapid test serve "as a fuzz target for the standard fuzzer". Select a separate scheduling method where needed ([README, comparison](https://raw.githubusercontent.com/flyingmutant/rapid/6706a6fd83736ba24aaf55ef2621fdf00c2c27e8/README.md)).
