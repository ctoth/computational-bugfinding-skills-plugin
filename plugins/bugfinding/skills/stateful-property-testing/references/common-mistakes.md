# Common stateful-testing mistakes

- **Wrong:** Sample unrelated object IDs and count every generated command as a deep API test. **Better:** Select useful live identities and count calls that execute; fast-check skips commands whose `check` is false ([runner source](https://raw.githubusercontent.com/dubzzz/fast-check/main/packages/fast-check/src/check/model/ModelRunner.ts)).
- **Wrong:** Copy the implementation's caches and decisions into its model. **Better:** Keep a simpler contract representation that can disagree for an independent reason ([fast-check model guidance](https://raw.githubusercontent.com/dubzzz/fast-check/main/website/docs/advanced/model-based-testing.md)).
- **Wrong:** A generation-time precondition proves every smaller sequence valid. **Better:** Recompute admissibility from the reduced prefix; RapidCheck explicitly requires shrink-time checks ([command contract](https://raw.githubusercontent.com/emil-e/rapidcheck/master/doc/state.md)).
- **Wrong:** Remove create/close/reopen because the visible state looks unchanged. **Better:** Retain the real setup until replay establishes it is irrelevant; Hughes documents a failure dependent on that hidden lifecycle ([paper, pp. 14-16](https://publications.lib.chalmers.se/records/fulltext/232550/local_232550.pdf)).
- **Wrong:** All returned values match, so storage/effects are correct. **Better:** Select independent observations for the actual promise; the same case study found corruption after model-consistent results ([Hughes, pp. 15-16](https://publications.lib.chalmers.se/records/fulltext/232550/local_232550.pdf)).
- **Wrong:** A skipped denial precondition tests permission enforcement. **Better:** Execute the deliberate denied call and assert its documented error and effects; skipping omits the call ([fast-check runner](https://raw.githubusercontent.com/dubzzz/fast-check/main/packages/fast-check/src/check/model/ModelRunner.ts)).
- **Wrong:** pytest function-scoped fixtures reset each generated input. **Better:** Use the actual machine lifecycle; Hypothesis explicitly warns that the fixture runs once per whole test ([compatibility](https://hypothesis.readthedocs.io/en/latest/compatibility.html)).
- **Wrong:** A fast-check seed/path contains everything needed for a command replay. **Better:** Retain `replayPath` and the executed transcript too ([replay guide](https://raw.githubusercontent.com/dubzzz/fast-check/main/website/docs/advanced/model-based-testing.md)).
- **Wrong:** Go Rapid provides coverage and schedule exploration automatically. **Better:** Ordinary Rapid lacks coverage feedback; its `MakeFuzz` adapter delegates input search to Go fuzzing. Select a separate scheduling method where needed ([README](https://raw.githubusercontent.com/flyingmutant/rapid/master/README.md)).
