# Stateful runtime recipes

These are conditional recipes for an existing fitting integration, not commands executed by this skill's author. Use the project's dependency and test runner conventions. Check the selected release, enabled configuration and actual APIs before changing a target. Links below are pinned to the commits read on 2026-11-07: Hypothesis tag `v6.170.15`, fast-check `main` at package version 4.10.2, Rapid `master` and RapidCheck `master`.

## Python: Hypothesis

Use `RuleBasedStateMachine.TestCase` with the existing unittest/pytest runner ("getting a unittest TestCase from it"). Bundles pass prior results to later rules; `consumes` removes a selected occurrence, and "Bundles can contain the same value more than once", so remaining aliases and permissions still need the target's explicit state model ([stateful guide, v6.170.15](https://raw.githubusercontent.com/HypothesisWorks/hypothesis/9ab0be61aaaa27396fc1bbf4b34e7925cc68d1e2/hypothesis/docs/stateful.rst), [Bundle and consumes source](https://raw.githubusercontent.com/HypothesisWorks/hypothesis/9ab0be61aaaa27396fc1bbf4b34e7925cc68d1e2/hypothesis/src/hypothesis/stateful.py)).

Use `@precondition` for admissibility and `@invariant` for the relevant post-operation property. Independent `@initialize` methods run once "in an arbitrary order" and "may not have preconditions"; express dependent initialization explicitly rather than assume declaration order ([initialize, precondition and invariant source](https://raw.githubusercontent.com/HypothesisWorks/hypothesis/9ab0be61aaaa27396fc1bbf4b34e7925cc68d1e2/hypothesis/src/hypothesis/stateful.py)). `stateful_step_count` bounds additional rule calls per example and is "effectively multiplicative with max_examples" ([settings source, stateful_step_count](https://raw.githubusercontent.com/HypothesisWorks/hypothesis/9ab0be61aaaa27396fc1bbf4b34e7925cc68d1e2/hypothesis/src/hypothesis/_settings.py)).

Reset/clean up through the actual per-machine lifecycle. A function-scoped pytest fixture runs "only once for the entire test, not per-input"; do not suppress the resulting `HealthCheck.function_scoped_fixture` warning to conceal shared state. The v6.170.15 compatibility page supports "CPython and PyPy 3.11+" and regularly tests macOS/Windows/Linux/Emscripten; recheck the selected version ([compatibility](https://raw.githubusercontent.com/HypothesisWorks/hypothesis/9ab0be61aaaa27396fc1bbf4b34e7925cc68d1e2/hypothesis/docs/compatibility.rst)).

Where installation is authorized, the official entrypoint is `pip install hypothesis`; use the project's environment. Run an existing machine test with its normal focused selector, such as `pytest path/to/test_world_state.py` ([quickstart](https://raw.githubusercontent.com/HypothesisWorks/hypothesis/9ab0be61aaaa27396fc1bbf4b34e7925cc68d1e2/hypothesis/docs/quickstart.rst)). License is MPL-2.0 "except where explicitly noted otherwise" ([license](https://raw.githubusercontent.com/HypothesisWorks/hypothesis/9ab0be61aaaa27396fc1bbf4b34e7925cc68d1e2/LICENSE.txt)).

## JS/TS: fast-check

Implement command `check`, `run` and readable `toString`; generate with `fc.commands`. Use `modelRun` for synchronous operations. For asynchronous operations, await `asyncModelRun` inside the awaited property execution: source awaits both admissibility and the command, `if (await cmd.check(m)) await cmd.run(m, r);`. A skipped `check` is not a target error ([commands arbitrary](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/packages/fast-check/src/arbitrary/commands.ts), [ModelRunner source, internalAsyncModelRun](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/packages/fast-check/src/check/model/ModelRunner.ts)).

Retain emitted assertion `seed`/`path` and the command arbitrary's `replayPath`; `replayPath` "Should be used in conjonction with `{ seed, path }`" [sic], and the guide's replay example also passes `endOnFailure: true`. Also save the executed command transcript and resolved identities. Scheduled commands are a separate controlled-execution concern, not an implication of choosing an asynchronous runner ([replay constraint source](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/packages/fast-check/src/check/model/commands/CommandsContraints.ts), [replay guide, Replay model-based tests](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/website/docs/advanced/model-based-testing.md), [runner source, scheduledModelRun](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/packages/fast-check/src/check/model/ModelRunner.ts)).

The pinned package manifest (version 4.10.2) declares MIT, ESM and Node `>=12.17.0`. That declared floor alone does not validate an application's runner, transpiler or module integration; inspect the selected package/lockfile and use its focused test invocation ([package manifest](https://raw.githubusercontent.com/dubzzz/fast-check/5ec2e3aceae60eb510b8b967bcb153274f3abad7/packages/fast-check/package.json)).

## Go: Rapid

Use an existing `rapid.Check` property, instantiate matching model/SUT state inside its execution and call `t.Repeat(actions)`. The empty-string action is checked initially and after admitted actions. `rapid.StateMachineActions(machine)` derives actions from eligible exported methods and supplies `Check` as that invariant hook, which "is executed before/after every other action invocation" ([state-machine implementation, Repeat and StateMachineActions](https://raw.githubusercontent.com/flyingmutant/rapid/6706a6fd83736ba24aaf55ef2621fdf00c2c27e8/statemachine.go)).

Select inputs from live model facts. Rapid retries a skipped action up to `validActionTries` (100 in the pinned source) and then fails the test with "can't find a valid (non-skipped) action"; `rapid.Check` also reports "only generated %v valid tests from %v total" when too many test cases are invalid. Diagnose both as generation/admissibility evidence before blaming the target. Keep deliberate invalid API calls as executable actions with their own oracle ([executeAction](https://raw.githubusercontent.com/flyingmutant/rapid/6706a6fd83736ba24aaf55ef2621fdf00c2c27e8/statemachine.go), [engine checkTB](https://raw.githubusercontent.com/flyingmutant/rapid/6706a6fd83736ba24aaf55ef2621fdf00c2c27e8/engine.go)).

For an existing test integration, replace the selector/path and choose positive counts from actual cost and budget:

```text
go test ./path/to/pkg -run '^TestWorldState$' -args -rapid.checks=COUNT -rapid.steps=STEPS
go test ./path/to/pkg -run '^TestWorldState$' -args -rapid.failfile=PATH
```

`rapid.steps` is the "average number of Repeat actions to execute", not an exact length or hard time ceiling; `-short` halves it. A failure message prints the reproduce flags, `-rapid.failfile=%q (or -rapid.seed=%d)`; preserve that fail file, seed, trace and Rapid version, because a fail file whose version "differs from rapid version" is ignored. Draws from a shared `rapid.T` are not concurrency-safe: "`*Generator.Draw` from a given `*T` is not" ([engine flags, checkTB, checkFailFile and T](https://raw.githubusercontent.com/flyingmutant/rapid/6706a6fd83736ba24aaf55ef2621fdf00c2c27e8/engine.go), [state-machine Repeat](https://raw.githubusercontent.com/flyingmutant/rapid/6706a6fd83736ba24aaf55ef2621fdf00c2c27e8/statemachine.go)).

Ordinary Rapid search "lacks coverage-guided feedback and mutations"; `rapid.MakeFuzz` adapts a property to `func(*testing.T, []byte)` for Go's fuzzer. This controls generated choices, not arbitrary goroutine scheduling ([README comparison](https://raw.githubusercontent.com/flyingmutant/rapid/6706a6fd83736ba24aaf55ef2621fdf00c2c27e8/README.md), [MakeFuzz source](https://raw.githubusercontent.com/flyingmutant/rapid/6706a6fd83736ba24aaf55ef2621fdf00c2c27e8/engine.go)). The pinned module declares Go 1.23; recheck the selected release. Source headers specify MPL-2.0 ([module](https://raw.githubusercontent.com/flyingmutant/rapid/6706a6fd83736ba24aaf55ef2621fdf00c2c27e8/go.mod), [state-machine source](https://raw.githubusercontent.com/flyingmutant/rapid/6706a6fd83736ba24aaf55ef2621fdf00c2c27e8/statemachine.go)).
