# Worked dependent reductions

These are this pack's illustrative experiment designs, not observed defects, external tool capabilities or executed campaigns. Establish each actual target guarantee before using the example.

## Program plus permissioned world

Suppose two engines return equal values, but a specified permitted mutation produces different persistent state. The evidence bundle contains the initial worlds, program, paired outcomes and selected effect witness.

Deleting object creation makes the source shorter but causes both engines to reject a missing reference. Reject that reduction: the promised operation no longer executes. Instead remove unrelated objects and operations with their uses, regenerate through the existing world/program producer, and compare equivalent starting worlds. If object IDs change, preserve a mapping showing which observable effect corresponds to the original witness.

The useful result may be a slightly larger self-contained world/program pair. A byte count alone is not this example's handoff objective. Do not create another parser or duplicate the production formatter merely to shrink it.

## Workload plus schedule

Suppose a controlled trace exposes a forbidden publication order. Removing a setup operation also removes a synchronization event, and the next schedule decision now names an absent task. The resulting controller error is unresolved for the original guarantee, not a smaller publication counterexample.

Remove irrelevant operations together with their corresponding decisions using the controller's supported representation. Replay the remaining trace and inspect the original safety witness. If no replay interface can establish correspondence, retain the original trace and partial reduction. Route scheduler semantics to `schedule-exploration`; this example supplies no drop-in Go scheduler/reducer.

## Acknowledgment plus fault boundary

Suppose a documented durability promise is violated after interruption. Removing earlier work shifts the nth-write fault before the relevant acknowledgment. The smaller workload now demonstrates a different experiment.

Retain the acknowledgment and the actual recorded failure event, then check recovered state. Use event identity through an existing seam where supported; an unchanged syscall ordinal is insufficient correspondence in this example. Stop with the best reproduced bundle when the seam cannot preserve the required boundary. `crash-consistency-testing` owns the failure-model and durability interpretation.

For each case, hand off original and reduced artifacts, the selected contract, admissible transformations, raw replay results, witness correspondence and why reduction stopped. These examples require demonstrated witness correspondence; cause attribution remains the triage skill's responsibility.
