# Common mistakes

The WRONG/RIGHT choices below are this pack's operational corrections, with their factual basis cited.

| WRONG | RIGHT | Why |
|---|---|---|
| Port target logic into a convenient solver language and call the result a target bug. | Link the actual target and preserve setup/environment; the paper's HiStar driver "creates the core kernel data structures" of the real kernel before symbolic calls ([KLEE, §§4 and 5.6](https://www.doc.ic.ac.uk/~cristic/papers/klee-osdi-08.pdf)). | A port is a different producer; its paths and bugs are the port's. |
| Assume the desired result, then celebrate an assertion pass. | Constrain the legal domain separately: execution "will only consider variable values which satisfy _condition_" ([assume semantics](https://raw.githubusercontent.com/klee/klee.github.io/6b3c0bff41807b3370655d58a43e91bdee24b3c0/docs/intrinsics.md)). | Values contradicting the assumed result are never explored, so the pass checks nothing. |
| Allow every external call to make unsupported code run. | Establish the real model/concretization boundary; `all` "concretizes any symbolic arguments in calls to external functions" and over-approx ignores the concretization afterwards ([Executor](https://raw.githubusercontent.com/klee/klee/2c11e515ed83608a0b01b48ffd5865a93b2a0b9f/lib/Core/Executor.cpp)). | A concretized call follows one value, not all values the real call could produce. |
| Use `replay_exit == 0` as the healthy-target oracle. | Inspect the native case diagnostics ("EXIT STATUS: ...") and property; the selected wrapper's `main` ends `return 0;` after `waitpid` ([replay loop](https://raw.githubusercontent.com/klee/klee/2c11e515ed83608a0b01b48ffd5865a93b2a0b9f/tools/klee-replay/klee-replay.c)). | A crashed or timed-out child still yields wrapper status 0. |
| Continue after a symbolic object mismatch to get a completed replay. | Preserve the exact names/sizes/order and repair the driver/test identity; `KLEE_RUN_TEST_ERRORS_NON_FATAL` only prints "Forcing execution to continue" ([intrinsics](https://raw.githubusercontent.com/klee/klee/2c11e515ed83608a0b01b48ffd5865a93b2a0b9f/runtime/Runtest/intrinsics.c)). | Mismatched objects get truncated, zero-filled or out-of-order bytes, so the run is a different input. |
| Count generated files or a helper timeout as complete search. | Distinguish proposals, checked candidates, pruned/killed attempts and confirmed violations; the helper records whether "the process was killed (e.g., out of memory, timeout)" ([SymCC helper](https://raw.githubusercontent.com/eurecom-s3/symcc/522c48070bc312aeb621a631ff130ded71507d6d/util/symcc_fuzzing_helper/src/symcc.rs)). | Killed and pruned attempts leave paths unexplored that a file count hides. |
| Mix old `QSYM_BACKEND` prose with a symcc-rt checkout other than the parent's submodule. | Verify actual compiler/runtime CMake (`SYMCC_RT_BACKEND`, backends "simple" and "qsym") and the selected parent submodule ([compiler](https://raw.githubusercontent.com/eurecom-s3/symcc/522c48070bc312aeb621a631ff130ded71507d6d/CMakeLists.txt), [runtime](https://raw.githubusercontent.com/eurecom-s3/symcc-rt/892f817f38f5abfa083dd0c1caa7ced821566bf5/CMakeLists.txt)). | Configuration.txt still documents `QSYM_BACKEND=ON/OFF`, which neither inspected CMake file reads ([configuration](https://raw.githubusercontent.com/eurecom-s3/symcc/522c48070bc312aeb621a631ff130ded71507d6d/docs/Configuration.txt)). |
| Increase solver time when a library concretizes the input. | Fix a demonstrated supported instrumentation/model boundary or record the omission: with the system library "we lose track of the corresponding symbolic expressions" ([C++ route](https://raw.githubusercontent.com/eurecom-s3/symcc/522c48070bc312aeb621a631ff130ded71507d6d/docs/C%2B%2B.txt)). | No solver budget restores expressions that were never recorded. |
| Count ExpoSE `[!]` entries or its exit code as target bugs. | Classify each entry; the same list receives "Exit code non-zero" and "a fatal error must have occured" ([Center.js](https://raw.githubusercontent.com/ExpoSEJS/ExpoSE/ec03edf85f883248612b1d498c6a7d9189d16d6f/Distributor/src/Center.js)), and the exit code is the number of paths with errors ([Distributor.js](https://raw.githubusercontent.com/ExpoSEJS/ExpoSE/ec03edf85f883248612b1d498c6a7d9189d16d6f/Distributor/src/Distributor.js)). | Analyser crashes and timeouts are counted with target failures. |
| Treat `expoSE replay` as native confirmation. | Run the input through the real entry point under the project's Node; `replay` runs Jalangi2 with `--analysis bin/Analyser.js` ([scripts/play](https://raw.githubusercontent.com/ExpoSEJS/ExpoSE/ec03edf85f883248612b1d498c6a7d9189d16d6f/scripts/play)). | Instrumented replay shares the analyser's models and faults. |
| Select ExpoSE for TypeScript, ESM, async or modern-syntax code without running it on the target. | Run the [applicability check](expose-javascript.md#applicability-check); the instrumenter uses Babel 6 presets and acorn `ecmaVersion: 6` ([Jalangi2 fork](https://raw.githubusercontent.com/ExpoSEJS/jalangi2/c2961c4374fa5f5fb35d114b98621cbe38b5c85f/src/js/instrument/esnstrument.js), [fork package.json](https://raw.githubusercontent.com/ExpoSEJS/jalangi2/c2961c4374fa5f5fb35d114b98621cbe38b5c85f/package.json)). | Unsupported code yields no paths or wrong paths, not evidence about the target. |
