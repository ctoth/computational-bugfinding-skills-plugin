# Common mistakes

| WRONG | RIGHT | WHY |
|---|---|---|
| Treat every watchdog timeout as starvation or deadlock. | Preserve the obligation, admissible environment and actual enabledness; CHESS relies on fairness and monitors, with imperfect replay limits, and its scheduler "might falsely think that the current thread is disabled" ([CHESS, §§4.2, 4.3 and 4.5](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/osdi2008-CHESS.pdf)). | A timeout shows only that a bound was hit; environment interference can produce a false deadlock. |
| Keep healing/restarting until the stalled operation appears healthy. | Retain a contract-supported healthy regime and persistent outside failures; the resonance resolved "when replica A is restarted and the retry counter is reset" ([TigerBeetle, Resonance](https://tigerbeetle.com/blog/2023-07-06-simulation-testing-for-liveness/)). | Restarts erase the failing retry state, so the livelock goes undetected. |
| Use a success-only task monitor for an API allowing cancellation. | Select the real discharge contract; Coyote's helper is satisfied only by `TaskStatus.RanToCompletion` ([task source, IsSatisfied](https://raw.githubusercontent.com/microsoft/coyote/2202e75a861f4e8a63149366c2e41ea21d73ae54/Source/Core/Specifications/Monitors/TaskLivenessMonitor.cs)). | An allowed cancellation would be reported as a liveness bug in the product. |
| Assume warm state advances Coyote's hot counter, or zero threshold strengthens checking. | Inspect the actual `this.ActiveState.IsHot && threshold > 0` condition ([Monitor](https://raw.githubusercontent.com/microsoft/coyote/2202e75a861f4e8a63149366c2e41ea21d73ae54/Source/Core/Specifications/Monitors/Monitor.cs)) and fair-iteration gate ([runtime](https://raw.githubusercontent.com/microsoft/coyote/2202e75a861f4e8a63149366c2e41ea21d73ae54/Source/Core/Runtime/CoyoteRuntime.cs)); the configuration says of threshold 0 "then it is disabled" ([Configuration, LivenessTemperatureThreshold](https://raw.githubusercontent.com/microsoft/coyote/2202e75a861f4e8a63149366c2e41ea21d73ae54/Source/Core/Configuration.cs)). | Zero turns the threshold check off; a warm suffix never reaches the threshold. |
| Add TLC `-deadlock` to enable detection. | Omit it when deadlock matters; the usage text says "if specified DO NOT CHECK FOR DEADLOCK" ([TLC.java](https://raw.githubusercontent.com/tlaplus/tlaplus/d8fb231de4e4b5d02c1b2ed1ac759c086f694021/tlatools/org.lamport.tlatools/src/tlc2/TLC.java)). | The flag sets `deadlock = false`, so a deadlocked model reports success. |
| Speed a liveness check with TLC symmetry sets or distributed mode. | Run liveness without symmetry in ordinary mode: "Symmetry sets should not be used when checking liveness properties" ([symmetry](https://raw.githubusercontent.com/tlaplus/tlaplus/d8fb231de4e4b5d02c1b2ed1ac759c086f694021/toolbox/org.lamport.tla.toolbox.doc/html/model/model-values.html)), and in distributed mode "TLC cannot check liveness properties" ([distributed mode](https://raw.githubusercontent.com/tlaplus/tlaplus/d8fb231de4e4b5d02c1b2ed1ac759c086f694021/toolbox/org.lamport.tla.toolbox.doc/html/model/distributed-mode.html)). | Symmetry can hide or invent liveness errors; distributed mode skips the check entirely. |
| Call state exploration complete while temporal checking is unfinished. | Retain the final liveness result and interruption state; `liveCheck.finalCheck` runs after exploration ([ModelChecker](https://raw.githubusercontent.com/tlaplus/tlaplus/d8fb231de4e4b5d02c1b2ed1ac759c086f694021/tlatools/org.lamport.tlatools/src/tlc2/tool/ModelChecker.java)). | Safety exploration finishing says nothing about the temporal property. |
| Treat synctest Wait or a frozen fake clock as schedule enumeration. | Inspect its internal durable-blocking contract and the actual pending producer; a goroutine is durably blocked when it "can only be unblocked by another goroutine in the same bubble" ([synctest](https://raw.githubusercontent.com/golang/go/dcc06a82727b447270b1a58cc5f86b49736e317c/src/testing/synctest/synctest.go)). | synctest supplies quiescence and fake time, not alternative interleavings. |
