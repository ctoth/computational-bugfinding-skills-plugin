# Common mistakes

| WRONG | RIGHT |
|---|---|
| Treat every watchdog timeout as starvation or deadlock. | Preserve the obligation, admissible environment and actual enabledness; CHESS relies on fairness and monitors, with imperfect replay limits ([CHESS, §§4.2–4.3 and 5](https://www.microsoft.com/en-us/research/wp-content/uploads/2016/02/osdi2008-CHESS.pdf)). |
| Keep healing/restarting until the stalled operation appears healthy. | Retain a contract-supported healthy regime and persistent outside failures; restarts can erase the failing retry state ([TigerBeetle, Resonance](https://tigerbeetle.com/blog/2023-07-06-simulation-testing-for-liveness/)). |
| Use a success-only task monitor for an API allowing cancellation. | Select the real discharge contract; Coyote's helper requires RanToCompletion ([task source](https://raw.githubusercontent.com/microsoft/coyote/2202e75a861f4e8a63149366c2e41ea21d73ae54/Source/Core/Specifications/Monitors/TaskLivenessMonitor.cs)). |
| Assume warm state advances Coyote's hot counter, or zero threshold strengthens checking. | Inspect the actual hot/positive-threshold condition and fair-iteration gate ([Monitor](https://raw.githubusercontent.com/microsoft/coyote/2202e75a861f4e8a63149366c2e41ea21d73ae54/Source/Core/Specifications/Monitors/Monitor.cs), [runtime](https://raw.githubusercontent.com/microsoft/coyote/2202e75a861f4e8a63149366c2e41ea21d73ae54/Source/Core/Runtime/CoyoteRuntime.cs)). |
| Add TLC `-deadlock` to enable detection. | The actual parser sets checking false for that flag ([TLC.java](https://raw.githubusercontent.com/tlaplus/tlaplus/d8fb231de4e4b5d02c1b2ed1ac759c086f694021/tlatools/org.lamport.tlatools/src/tlc2/TLC.java)). |
| Speed a liveness check with TLC symmetry sets or distributed mode. | Those modes cannot supply this supported claim: symmetry can miss/invent errors, and distributed mode excludes liveness ([symmetry](https://raw.githubusercontent.com/tlaplus/tlaplus/d8fb231de4e4b5d02c1b2ed1ac759c086f694021/toolbox/org.lamport.tla.toolbox.doc/html/model/model-values.html), [distributed mode](https://raw.githubusercontent.com/tlaplus/tlaplus/d8fb231de4e4b5d02c1b2ed1ac759c086f694021/toolbox/org.lamport.tla.toolbox.doc/html/model/distributed-mode.html)). |
| Call state exploration complete while temporal checking is unfinished. | Retain the final liveness result and interruption state ([ModelChecker](https://raw.githubusercontent.com/tlaplus/tlaplus/d8fb231de4e4b5d02c1b2ed1ac759c086f694021/tlatools/org.lamport.tlatools/src/tlc2/tool/ModelChecker.java)). |
| Treat synctest Wait or a frozen fake clock as schedule enumeration. | Inspect its internal durable-blocking contract and the actual pending producer; it supplies quiescence/fake-time support ([synctest](https://raw.githubusercontent.com/golang/go/dcc06a82727b447270b1a58cc5f86b49736e317c/src/testing/synctest/synctest.go)). |
