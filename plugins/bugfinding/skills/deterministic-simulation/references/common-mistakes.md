# Common mistakes

| Wrong interpretation | Correct action and source |
|---|---|
| “A simulator ran, so every dependency was controlled.” | Inspect actual environmental seams and omissions. FDB's paper excludes non-Flow dependencies and records weaker OS contracts as a blind spot ([§4 p. 9](https://www.foundationdb.org/files/fdb-paper.pdf)). |
| “More failures always find deeper bugs.” | Measure reached states; excessive faults can collapse the search, and a recoverable regime is needed for a recovery assertion ([FoundationDB §4 p. 9](https://www.foundationdb.org/files/fdb-paper.pdf)). |
| “Random eventual healing tests persistent progress failures.” | Keep the specific contract's healthy environment while preserving relevant outside failures where supported; restarts may erase the failure ([TigerBeetle liveness account](https://tigerbeetle.com/blog/2023-07-06-simulation-testing-for-liveness/)). |
| “This Gosim module supports any recent Go/compiler/CGO project.” | Verify selected families, platforms and CGO-disabled source loading; choose a different fitting method for unsupported targets ([family table](https://raw.githubusercontent.com/neria-cloud/gosim/64ac3b2a20806bb4f9470232e12fabdfd5d13852/internal/buildspec/families_gen.go), [loader](https://raw.githubusercontent.com/neria-cloud/gosim/64ac3b2a20806bb4f9470232e12fabdfd5d13852/internal/translate/load.go), [README](https://raw.githubusercontent.com/neria-cloud/gosim/64ac3b2a20806bb4f9470232e12fabdfd5d13852/README.md)). |
| “Graceful Stop and Crash are equivalent recovery controls.” | Preserve actual termination/durability semantics; these use different requests ([machine controls](https://raw.githubusercontent.com/neria-cloud/gosim/64ac3b2a20806bb4f9470232e12fabdfd5d13852/machine_sim.go)). |
| “The same seed always replays after a build change.” | Retain full build/replay identity and actual replay evidence ([Gosim RunInfo](https://raw.githubusercontent.com/neria-cloud/gosim/64ac3b2a20806bb4f9470232e12fabdfd5d13852/rt/info.go), [VOPR seed/commit](https://raw.githubusercontent.com/tigerbeetle/tigerbeetle/68958eb757747d0fc96a79d1f9c2fa6766b67b48/docs/internals/vopr.md)). |
| “MaxStates exhausted means every filesystem outcome is safe.” | Report the explicit model budget and retained snapshots; bounded enumeration is not real-filesystem exhaustion ([recovery declarations](https://raw.githubusercontent.com/neria-cloud/gosim/64ac3b2a20806bb4f9470232e12fabdfd5d13852/fs/recovery.go), [implementation](https://raw.githubusercontent.com/neria-cloud/gosim/64ac3b2a20806bb4f9470232e12fabdfd5d13852/fs/recovery_sim.go)). |
| “Virtual time predicts native performance.” | Keep actual performance and hardware/OS testing complementary ([FDB testing](https://raw.githubusercontent.com/apple/foundationdb/7e7611f8270952a2b1cffd75aa523c4b057afd62/documentation/sphinx/source/testing.rst), [paper §4 limitations](https://www.foundationdb.org/files/fdb-paper.pdf)). |
